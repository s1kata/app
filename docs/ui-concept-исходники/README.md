# TravelHub — концепт интерфейса 2026

Папка: все экраны текущего приложения в одном визуальном стиле.

- Тёмный navy + бирюза + коралловые кнопки
- Крупные фото отелей/стран

- Мало текста, крупные кнопки
- Как у сильных туроператоров 2026
